# 内部试用版验证记录

日期：2026-09-14。机器：macOS 14.8.4（23J319）、Apple Silicon arm64。工具链：Node.js 24.10.0、npm 11.6.0、Rust 1.91.0、系统 Command Line Tools。

## 自动化验证

- `npm run build`：TypeScript 与 Vite 生产前端构建通过。
- `npm run check`：TypeScript + Cargo Clippy 全目标，`-D warnings`，通过。
- `npm test`：15 项 Rust 集成测试通过，0 失败。
- `npm run tauri build -- --bundles app`：生成原生 Release `.app`。
- `codesign --verify --deep --strict --verbose=2`：本地完整包 ad hoc 签名校验通过，valid on disk。
- 最终 Release 的隔离 QA 副本通过 LaunchServices 启动；读取原有 3 个服务、13 个配置目标和待应用状态。QA 副本仅修改应用标识及测试目录环境变量，交付包未带入这些测试环境变量。

测试覆盖：

1. 12 个适配器的能力范围、格式往返、其他配置与注释保留。
2. 来源专属原生字段保留、不支持结构拒绝接管。
3. 基于各工具官方示例的 HTTP 输出独立断言，包括 Cline / Roo 不同类型字段。
4. 精确恢复原始文件、重开服务库仍保持正确基线。
5. 预览后外部修改会阻止写入。
6. 已有配置纳入管理不产生写入；外部冲突的显式处理。
7. 未管理同名条目不会被静默覆盖。
8. 整批导入原子性、移除与撤销。
9. 中断日志自动恢复；外部编辑保留并进入待处理状态。
10. 恢复状态落盘与历史落盘之间再次中断，重启后仍阻止直接写入。
11. 保留当前磁盘文件可解除恢复阻塞，并能持久化。
12. 后来修改的文件不被历史恢复覆盖；同一工作区进程锁。
13. 脱敏保留数组等必要结构。
14. 路径别名 / 数据目录冲突、重复 JSON 属性名阻止歧义写入。
15. 第二个文件写入失败时，前一个文件恢复。

部分测试函数同时覆盖多个场景；以上为验收点，不是测试函数逐一对应列表。测试仅在项目临时目录运行。
