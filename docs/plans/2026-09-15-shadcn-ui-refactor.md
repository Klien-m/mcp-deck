# shadcn/ui 界面与主题设置

**Goal:** 在独立 worktree 内将 MCP Deck 的常用交互迁移到 shadcn/ui，提供可运行桌面预览，并增加主题设置页面。

**Architecture:** 复用现有服务库、IPC 和 Rust 引擎。以官方 shadcn/ui New York / Radix 组件作为控件层；主题通过语义 CSS 变量贯穿三栏工作区、弹窗和设置页面。外观偏好独立保存在本机 localStorage，跟随系统模式监听系统配色变化；原生标题栏设为透明并同步窗口背景色及原生主题。

**Tech Stack:** React 19、TypeScript、Vite、shadcn/ui、Radix UI、Tailwind CSS 4、Tauri 2。

## 设计

- 灰白纸面与石墨文字，强调信息层级、细边框和克制的阴影；深色模式使用炭灰背景，保留状态色。
- 三栏结构继续承载工具、服务库、配置详情；更新导航、搜索、详情页签和工具分配开关。
- 新增独立「偏好设置」页，提供浅色、深色、跟随系统三个主题选项，即时生效并记住选择；另设石墨 / 经典绿配色，两种配色均支持上述明暗模式。
- 按用户确认提高最低系统版本至 macOS 13.3，使用 Tailwind 4 与官方新版 shadcn/ui 组件；CSS 构建目标为 Safari 16.4。
- 按钮、输入框、选择器、弹窗、复选框、开关、页签与徽标采用真实 shadcn/ui 组件；避免仅换色或未接业务的演示界面。

## 实施与验证

1. 配置 Tailwind、路径别名与 components.json，导入官方组件源码。
2. 迁移公共 Modal / Select 及业务控件，保留异步锁、错误、键盘和提交行为。
3. 增加主题控制和设置页，将现有布局样式接入主题变量。
4. 执行类型检查、Rust 测试和构建；隔离样例验证引导导入、表单选择、主题切换/持久化与窄窗口布局。
5. 构建独立预览应用并打开，供用户检查效果；用户确认后合并 master 并清理 worktree。
